## Descrições Funcionais

### Exercício 1 – Validador de Senhas Fortes
Este exercício solicita que o usuário digite uma senha e, em seguida, verifica se ela é considerada forte com base em quatro critérios: ter pelo menos 8 caracteres, conter ao menos uma letra maiúscula, um número e um caractere especial. O programa analisa cada caractere da senha digitada e, ao final, informa se a senha atende a todos os requisitos ou exibe uma mensagem explicando o que está faltando.

### Exercício 2 – Tabuada Completa com Laço
Este exercício pede que o usuário digite um número e, com base nesse valor, o programa exibe a tabuada completa dele, de 1 a 10. Utilizando um laço for, o código multiplica o número informado por cada valor de 1 a 10 e mostra o resultado na tela.

### Exercício 3 – Calculo de Fatorial com while
Este exercício solicita que o usuário informe um número inteiro positivo e, utilizando a estrutura de repetição while, o programa calcula o fatorial desse número. Ele faz isso multiplicando o número por todos os inteiros menores que ele até chegar a 1, mostrando o resultado final na tela.

### Exercício 4 – Conversor de Temperaturas com Menu
Este exercício apresenta um menu com três opções: converter Celsius para Fahrenheit, Fahrenheit para Celsius e sair. Utilizando um laço while, o menu permanece ativo até que o usuário escolha sair. A estrutura switch trata cada opção do menu, permitindo ao usuário fazer as conversões desejadas ou encerrar o programa.

### Exercício 5 – Verificador de Palíndromos
Este programa solicita ao usuário uma palavra ou frase. Em seguida, ele analisará o texto, ignorando acentuação e espaços, para verificar se a string é um palíndromo (ou seja, se permanece igual quando lida de trás para frente).

### Exercício 6 – Cadastro Simples de Produtos 
Este programa solicita ao usuário o nome, a quantidade e o valor de 3 instâncias da classe Produto. Em seguida, ele retornará uma lista com a quantidade e o valor total (preço × quantidade) de cada produto.

### Exercício 7 – Soma de Números Pares de um Array
Este programa solicita ao usuário 10 números. Apenas os números pares serão considerados para a soma, cujo resultado será exibido ao final.

### Exercício 8 – Cálculo de IMC com Classificação
Este programa solicita ao usuário seu peso (em kg) e altura (em metros), calcula o Índice de Massa Corporal (IMC) e informa a classificação correspondente com base nos padrões da Organização Mundial da Saúde:
- Abaixo de 18.5: Abaixo do peso
- 18.5 a 24.9: Peso normal
- 25 a 29.9: Sobrepeso
- 30 ou mais: Obesidade

### Exercício 9 – Jogo da Adivinhação
Este programa gera um número aleatório entre 1 e 100 e pede que o usuário tente adivinhar esse número. A cada tentativa, o sistema informa se o número inserido é maior ou menor que o número secreto. O jogo continua até que o usuário acerte, e no final é exibido o número total de tentativas realizadas.

### Exercício 10 – Lista de Tarefas (To-Do List)
Este programa permite ao usuário criar e gerenciar uma lista de tarefas. É possível:
- Adicionar novas tarefas
- Listar todas as tarefas (com indicação se estão concluídas ou não)
- Marcar tarefas específicas como concluídas

As tarefas são armazenadas em uma List<string> e o status de conclusão é gerenciado com uma List<bool>. O sistema opera por meio de um menu interativo no console.
